# Contributing

> **MVP:** this is a first version. It will change as the project does, and you're welcome to suggest changes to it too.

Thanks for being here. You don't need to code to contribute, and you don't need to be an expert.

## Ways to take part

1. **Answer a question.** Pick any question in the [multi-player spec](Game%20of%20Life%20multi-player%20spec.md) and answer it in a comment, or tell us why it's the wrong question.
2. **Ask a better one.** New questions are a contribution.
3. **Take a good first issue.** Look for the `good first issue` label.
4. **Fork it.** Take the guide to a different cause or community. You don't need permission. Please keep the credit and license (see the README).
5. **Share the room you're in.** Just the room. No names, no details.

## Before you start

- Read the README's "What this is not" section.
- The one fixed rule: nothing here uses anyone's information without their clear opt-in. See [CONSENT-AND-DATA.md](CONSENT-AND-DATA.md).
- Don't post personal details about yourself or anyone else.

## Ideas we can't use yet

We won't dismiss them. They get the label `parking lot`: "good idea, parked for 2.0."

## Changing files

Small fixes (typos, links): open a pull request. Larger changes (rewrites, new sections): open an issue first so we can talk about it. Please change one thing at a time.
