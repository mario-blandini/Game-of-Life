# Security and Privacy Reports

> **MVP:** this is a first version and will evolve with the project.

This repo is mostly documents, so the main risk isn't a software bug. It's someone's personal information being shared when it shouldn't be.

## If you see personal information

For example: a name, a place, contact details, or a story that identifies someone, especially a young person.

1. **Don't reply or repeat it in public.**
2. Report it privately to mblandini@gmail.com until a volunteer maintainer is identified.
3. Tell us where you saw it (link) and what it is. We'll remove it as soon as we can.

## If it's your information

Tell us the same way. We'll remove it and won't ask you to explain why.

## If you find a security problem in code

If a tool or script is added to this repo, report any security problem privately to mblandini@gmail.com until a volunteer maintainer is identified, not in a public issue.

## What to expect

We'll acknowledge the report as soon as we can. We can't promise a timeline yet, and we can't undo copies others have already made.
